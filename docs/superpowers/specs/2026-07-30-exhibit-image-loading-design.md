# 展示圖片逐張載入設計

## 目標

當展示櫃與本月選書的遠端圖片仍在下載時，保留圖片預定位置並以符合書店夜間展間風格的動態取代空白。每張圖片獨立完成，不等待同一面板的其他圖片。

## 視覺方向

採用「細框描繪」：深棕底上的暖金色細線沿著作品框四邊循環描繪，完成一圈後以低幅度明暗呼吸等待圖片顯示。此意象是展台與作品框，而非書本，因此同時適用畫作、手作商品與其他展示品。

- 不使用載入文案或通用轉圈圖示。
- 色彩延續既有 overlay：深棕黑背景、米白文字、暖金色點綴。
- `prefers-reduced-motion: reduce` 時停止描繪與呼吸，保留靜態框線。

## 元件與資料流

建立可重用的 `ImageFrame` 元件，接收 `src`、`alt`、`fit` 與載入框的尺寸／比例設定。

1. 元件初始顯示細框 Loading，並建立圖片請求。
2. 單張圖片觸發 `load` 後淡入圖片並移除 Loading。
3. 單張圖片觸發 `error` 後顯示既有錯誤呈現；展示櫃保留重試按鈕，選書封面以不破壞清單排版的失敗框呈現。
4. 展示櫃翻頁時，新的圖片回到自己的 Loading 狀態；既有下一頁預載行為維持。
5. 本月選書每本封面各自追蹤狀態，其他已完成的封面立即可見。

## 版面與可近用性

- 展示櫃 Loading 延續作品區域，使用彈性的最大尺寸與保守的直式作品比例，避免打斷標題、說明與頁碼。
- 本月選書 Loading 固定為現有的 80×112px 封面尺寸，完全消除清單中的版面跳動。
- 裝飾性 Loading 對輔助科技隱藏；圖片完成後仍由原有的替代文字說明內容。
- 瀏覽器不支援動畫時，靜態細框仍可表達等待狀態。

## 驗證

- 單元測試確認展示櫃第一頁、翻頁後的圖片在載入前皆顯示 Loading，`load` 後只顯示圖片。
- 單元測試確認本月選書的封面分別在 `load` 前後切換，且一張完成不影響其他封面。
- 回歸圖片錯誤與展示櫃重試行為。
- 執行型別檢查、完整單元測試與 production build。
