# 隨機空間角色設計

## 目標

讓每次進入書店空間都有不同陪伴感，降低單一男性旅人長期出現的單調性，同時完整保留既有角色的操作手感與空間規則。

## 角色池

系統提供下列五種玩家外觀；每種在單次抽選中的機率皆為 20%。

| ID | 角色 | 視覺方向 |
| --- | --- | --- |
| `visitor-male` | 原本男性旅人 | 保留現有造型與素材。 |
| `visitor-female` | 女觀光客 | 人類觀光客的唯一女性版本，與原角色同樣具書店訪客感。 |
| `friendly-alien` | 友善外星人 | 圓潤、玩偶般、柔和暖色，不使用尖銳或驚嚇感的設計。 |
| `big-yellow-dog` | 大黃狗 | 圓潤親切、比例可讀；可有耳朵或尾巴的細微動態。 |
| `orange-cat` | 橘貓 | 溫暖橘色、表情簡潔；可有耳朵或尾巴的細微動態。 |

現有男性旅人的實際遊戲顯示尺寸為所有角色的最大尺寸基準。女觀光客可與其等高；外星人、大黃狗與橘貓只能維持相同或更小的等比例視覺尺寸，不得因身體寬度、頭部或配件而顯得更大。所有新角色必須以現有男性旅人的 sprite 為唯一風格基準，延續其緊湊比例、低飽和暖色、像素貼圖、細緻深色陰影與小尺寸可讀性；不得採用兒童繪本、3D 黏土或過度 Q 版的視覺語言。可為角色加入共同的小背包、托特包或閱讀小物，讓五者明確屬於同一座書店空間。

## 使用者行為與生命週期

1. 使用者成功載入並進入書店空間時，系統從五種角色中等機率抽選一種。
2. 系統依抽選結果建立玩家外觀。
3. 在該次空間存續期間，玩家外觀固定不變；開關互動面板、視窗縮放與裝置旋轉均不得重抽。
4. 使用者離開空間後再次進入時重新抽選；允許抽到與前次相同的角色。
5. 瀏覽器重新整理視同一次新的空間載入，因此必須重新抽選。
6. 不顯示角色名稱、抽選結果、機率或「換角色」控制項。
7. 抽選結果不得寫入帳號、localStorage、sessionStorage、網址參數、CMS 或任何後端服務。

## 行為不變量

角色差異只能影響視覺外觀。以下行為對所有角色完全一致：

- 移動速度、方向輸入、四方向行走與待機狀態。
- 攝影機跟隨、縮放與畫面中的站位感。
- 碰撞範圍、碰撞偏移、世界邊界與出生位置。
- 互動範圍、互動權限、暫停規則與所有遊戲內容規則。

動物與外星人必須以相同腳底基準與中心對齊方式繪製，並在上述最大尺寸基準內等比例縮放，讓角色站在地面、桌椅遮擋與碰撞表現都與人類角色一致。不同角色可以有尾巴、耳朵等非核心裝飾動畫，但不得改變行走節奏或移動判定。

## 技術設計

### 角色外觀資料

建立單一角色外觀資料表作為角色池的唯一來源。每筆資料至少包含：

- 穩定的角色 ID。
- 對應的 sprite sheet 素材與 Phaser texture key。
- 共用四方向動畫所需的 frame layout 設定。
- 對齊與碰撞設定；初始版本五名角色應使用相同數值。

選擇函式只接受可注入的亂數來源，回傳角色池中的其中一筆資料。正式執行時使用 `Math.random`；測試可用受控亂數覆蓋五個分支。

### 建立順序

角色選擇在「空間成功進入」生命週期只執行一次，並把結果傳入玩家建立流程。素材預載可載入五種角色，然而實際玩家 sprite、動畫 key 與 texture 只能使用該次選中的一種。

玩家控制、移動、碰撞、攝影機與互動邏輯保持與外觀選擇分離。外觀層不應自行監聽每幀更新、UI 開關、視窗 resize 或互動事件，也不得再次執行隨機選擇。

### 素材契約

每個角色使用相同的 4×4、四方向 sprite sheet 契約：

- 圖格尺寸與透明背景符合現有玩家素材格式。
- 列順序：下、左、右、上。
- 欄順序：待機、接觸、經過、反向接觸。
- 每格的腳底基準與水平中心對齊既有玩家規格。

這個契約使所有外觀共用相同行走動畫與物理設定，避免角色類型滲入控制邏輯。

## 錯誤處理

若任何角色素材載入失敗，空間不可進入，並沿用既有素材載入失敗畫面。不得在失敗後重新抽選其他角色，以免抽選結果、錯誤重現與測試結果不一致。

## 測試與驗收

### 單元測試

- 選擇函式只會回傳五個指定角色之一。
- 分別注入五個對應區間的亂數，驗證五個角色分支與 20% 區間邊界。
- 驗證選擇函式不讀寫瀏覽器儲存、網址或帳號資料。

### 整合測試

- 成功建立空間時只選擇一次角色，並用該外觀建立玩家。
- 在同一空間內開關互動面板、更新迴圈、resize／旋轉後，不得再次選擇或替換外觀。
- 摧毀並重建空間（含瀏覽器重新整理的等效流程）時，必須重新呼叫選擇函式；測試中可固定亂數來證明新一輪結果會被採用。
- 五種外觀均使用同一份移動速度、碰撞外框、互動區判定與攝影機設定。

### 素材與視覺驗收

- 五張 sprite sheet 均符合 4×4 格線、透明背景、共同腳底基準與水平中心的素材驗證。
- 逐一在既有書店場景確認：角色不高於現有男性旅人的實際顯示尺寸、地面貼合、家具遮擋、出生位置、四方向待機與走路動畫、桌機與手機攝影機可讀性。
- 外星人看起來友善玩偶化；貓狗能清楚辨認而不顯得過大、漂浮或穿模。

## 非目標

- 不提供角色選擇器、重抽按鈕、角色名稱提示或收藏系統。
- 不同步或保存角色選擇結果。
- 不做空間內即時變身。
- 不因角色類型改變遊戲規則、能力、速度、權限、碰撞或互動。
