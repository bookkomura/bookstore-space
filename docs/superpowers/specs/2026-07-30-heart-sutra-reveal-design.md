# 心經拂霧互動 — 設計規格

日期：2026-07-30  
狀態：已與 Pai 完成 brainstorming 逐段確認，待書面審閱

## 1. 背景與目標

實體書店有一處供客人抄寫《般若波羅蜜多心經》的座位。虛擬書店需要在對應空間加入一個可辨識、可短暫體驗的互動點，讓訪客透過安靜的意境互動，自然理解書店裡有「抄寫心經」這件事。

本功能的核心不是宣傳、導覽或線上抄經模擬，而是讓訪客用約 10–15 秒，以手指或滑鼠拂去宣紙薄霧，顯現一段隨機的心經短句。體驗結束後只留下經文，不顯示來店呼籲、位置、營業時間、預約方式或其他宣傳文字。

本次不做：

- 不要求訪客描字、臨寫或輸入文字。
- 不判斷筆畫，不提供分數、倒數、進度條、成功音效或獎勵動畫。
- 不播放音樂、環境聲或鈴聲。
- 不保存筆跡、操作軌跡或完成紀錄。
- 不增加帳號、後端服務、CMS 欄位或分析追蹤。
- 不改變既有「拾字成詩」、店長選書與其他互動點。

## 2. 採用方案與取捨

採用「桌面經紙識別＋拂霧顯經覆蓋畫面」。

場景中的中央長桌左端會出現一張小幅經紙與一支筆，玩家靠近時看到既有樣式的驚嘆號與「抄寫心經」名稱。觸發後，書店背景稍微變暗，中央展開宣紙；訪客拂過紙面時，霧氣沿手勢散開並逐步顯露經文。

這個方案兼顧三件事：

1. 場景中的經紙、筆和固定名稱直接說明實體書店有抄經座位。
2. 拂霧手勢保留抄經的緩慢、專注與留白，但不把宗教文本變成寫字闖關。
3. 手勢不需精準描字，手機與桌機都能在短時間內完成。

未採用的方案：

- **墨跡洇開**：畫面雅緻，但訪客只需點一下等待動畫，參與感較弱。
- **燈影照見**：氣氛鮮明，但更像探索遊戲，與實體抄經的連結較間接。
- **真實描字或自由臨寫**：更接近抄經行為，但手機書寫容易變成操作考驗，也需要額外處理筆跡、輸入與完成判斷。

## 3. 場景配置

### 3.1 位置

- 新互動點 ID 為 `sutra-1`，互動類型為 `sutra`。
- 位置是現有背景圖中央長桌左端的空桌面，即使用者在參考圖中紅圈標示的位置。
- 桌面顯示一張小幅宣紙與一支筆，風格需符合現有場景的像素密度、暖色光源、低飽和配色與俯視角度。
- 經紙與筆製作成透明背景的小型場景素材，疊放於背景之上，不直接覆寫 `store-background.png`。
- 互動標記錨定在經紙附近；啟用範圍放在長桌左端旁的可行走地面，不得要求玩家進入桌子或椅子的碰撞範圍。
- 啟用範圍不得與中央長桌既有「店長選書」及「拾字成詩」區域重疊。若校準時無法完全分離，必須縮小或移動 `sutra-1`，不可依賴最近距離規則讓訪客猜測目前選中的互動。

### 3.2 場景狀態

- 遠距狀態沿用既有白底灰字驚嘆號。
- 靠近後沿用既有標記啟用樣式，名稱固定為「抄寫心經」。
- 手機使用既有互動按鈕；桌機使用既有鍵盤與鄰近標記點擊方式。
- 開啟體驗時凍結角色與場景輸入；關閉後回到原本位置並恢復操作。

## 4. 完整體驗流程

1. 玩家走近中央長桌左端，看到「抄寫心經」互動名稱。
2. 訪客觸發互動後，角色停止，書店背景稍微變暗，中央出現一張暖白色宣紙。
3. 宣紙覆有半透明薄霧，底下墨字僅隱約可見。
4. 手機顯示「以指尖輕拂紙面」，桌機顯示「以游標輕拂紙面」。旁邊的半透明指尖會緩慢示範一次短距離拂動。
5. 訪客第一次碰到紙面時，提示文字與指尖立即淡出。
6. 若四秒內沒有操作，指尖再示範一次，之後不再循環。
7. 訪客按住滑鼠拖曳，或以手指在紙面移動；手勢經過的區域會散去霧氣。
8. 當 70% 的可互動紙面被拂開後，剩餘薄霧自然淡出，完整短句留在紙上。
9. 畫面不出現完成提示或宣傳文字，只保留完整經文與關閉按鈕。
10. 訪客可在任何階段關閉，不必完成。
11. 同一瀏覽器分頁的生命週期內固定使用同一句經文；重新整理頁面仍維持該句。關閉分頁後的下一次造訪會重新隨機抽選，但允許因隨機結果而再次抽到相同句子。
12. 同一分頁內重新打開互動時仍顯示相同短句，但薄霧與操作進度重新開始。

正常操作約需 10–15 秒，但畫面不顯示或強制任何時間限制。

## 5. 視覺與動態

- 經文採直排，依短句長度排成一至兩列，保留充分留白。
- 文字使用支援繁體中文的沉靜手寫楷體；優先沿用專案既有的 `LXGW WenKai TC` 字體堆疊。
- 宣紙使用暖白色、淡纖維紋理與柔和邊緣，避免純白卡片感。
- 墨色使用帶暖度的深灰黑，不使用純黑。
- 薄霧保持半透明、低對比且移動緩慢，不能做成刮刮樂銀漆、橡皮擦碎屑或遊戲煙霧。
- 背景只做輕微變暗，不模糊到失去書店空間感。
- 所有動態均不伴隨聲音。

## 6. 元件與資料流

維持現有「Phaser 管場景、Vue 管覆蓋介面」的分工。

### 6.1 場景層

- 場景設定加入 `sutra-1` 固定互動區與桌面經紙素材。
- 互動名稱對照加入固定文字「抄寫心經」。
- Phaser 只負責玩家鄰近判斷、標記狀態與派送 `{ id: 'sutra-1', type: 'sutra' }`。
- 既有 `EventBridge` 仍是場景與 Vue 之間的唯一事件通道，不增加平行狀態來源。

### 6.2 覆蓋介面

- 新增獨立的心經拂霧元件，負責宣紙、經文、薄霧畫布、操作提示、完成判定與關閉控制。
- 薄霧使用覆在經文上方的互動畫布。指標移動時只清除經過區域；達到 70% 覆蓋門檻後，元件淡出剩餘霧層。
- 觸控只在宣紙範圍內攔截頁面捲動，宣紙以外的關閉控制保持正常。
- 元件開啟時送出既有 `ui:opened` 流程；關閉時送出 `ui:closed`。

### 6.3 經文選擇

- 經文片段是內建且人工校對的固定清單，不在執行時從全文任意截取。
- 第一次開啟時隨機選出一段，並以瀏覽器 `sessionStorage` 保存；因此同一分頁重新整理後仍維持該句，關閉分頁即結束這次暫存。
- 若暫存值不存在清單中，忽略舊值並重新抽選，避免日後清單變更造成無效內容。
- 不保證相鄰兩次造訪一定不同；隨機抽選允許重複。

## 7. 經文內容

文字採常見的玄奘譯本繁體內容，使用下列七段完整短句：

1. 照見五蘊皆空，度一切苦厄
2. 色不異空，空不異色
3. 色即是空，空即是色
4. 不生不滅，不垢不淨，不增不減
5. 心無罣礙，無有恐怖
6. 遠離顛倒夢想，究竟涅槃
7. 能除一切苦，真實不虛

清單中的字詞與標點視為內容合約。修改或增加短句前，需再次對照同一譯本校對，且不得以固定字數從全文自動切割。

## 8. 可近用性與替代操作

- 宣紙互動區可由鍵盤聚焦。按 Enter 或 Space 會完整揭示經文，不要求鍵盤使用者模擬拖曳。
- 關閉按鈕可聚焦，具清楚的中文可存取名稱，並支援既有 Escape 關閉行為。
- 經文以真實文字保留在文件結構中，不只畫在 canvas 上，讓輔助閱讀工具可以讀取。
- 操作提示需與裝置相符，不對觸控裝置顯示「游標」，也不對純鍵盤操作隱藏替代方式。
- 偏好減少動態效果時，不播放指尖示範；霧層以短暫淡出取代流動動畫。
- 文字與宣紙、關閉按鈕與背景皆需具足夠對比。

## 9. 響應式與狀態保存

- 手機直向時，宣紙占據可視區域的大部分，但不得遮住關閉按鈕或超出安全區域。
- 手指不需精準沿著字形移動；自然來回拂動即可達成門檻。
- 桌機與橫向裝置維持宣紙比例與直排文字，不拉伸紋理。
- 視窗改變尺寸或手機旋轉時，保留目前短句、已拂開比例與完成狀態。
- 關閉後重新開啟會重置霧層；句子仍依同一分頁生命週期規則保持不變。

## 10. 錯誤處理

| 情境 | 處理 |
|---|---|
| 霧層畫布無法建立或執行 | 直接顯示完整經文與關閉按鈕 |
| 暫存的經文值已不在清單中 | 忽略舊值並重新抽選 |
| 桌面經紙素材載入失敗 | 互動標記與功能仍可使用；開發環境記錄素材錯誤 |
| 視窗旋轉造成畫布尺寸改變 | 依比例重建霧層並還原既有揭示進度 |
| 訪客未操作 | 保持安靜畫面；四秒後只重播一次指尖提示，不自動完成 |
| 訪客中途關閉 | 正常關閉並恢復場景；不顯示失敗或確認訊息 |

## 11. 測試策略

### 11.1 單元與元件測試

- 場景設定包含唯一的 `sutra-1`，類型、固定名稱與位置正確。
- `sutra-1` 的可行走啟用範圍不與既有中央長桌互動區重疊。
- 隨機結果只會來自七段已校對清單。
- 同一分頁生命週期內重複開啟與重新整理保持同一句。
- 無效暫存值會重新抽選；新的分頁生命週期可以重新抽選。
- 手機與桌機顯示正確的操作提示。
- 第一次操作會隱藏提示；四秒未操作只重播一次示範。
- 揭示比例未達 70% 時保留霧層，達到門檻時完整淡出。
- 關閉再開啟時霧層重置，但經文不變。
- Enter、Space、Escape 與關閉按鈕均產生正確結果。
- 偏好減少動態效果時不播放指尖動畫。
- 畫布建立失敗時仍顯示完整經文。

### 11.2 瀏覽器驗收

- 桌機：從入口抵達長桌左端，以既有鍵盤操作開啟、拂霧、完整顯示經文並關閉。
- 手機：看見「抄寫心經」名稱後，使用既有互動按鈕開啟；不需外部說明即可從提示理解手勢。
- 手機：自然來回拂動可在約 10–15 秒內完成，不需精準觸碰字形或紙面角落。
- 開啟期間角色不移動；關閉後回到原位並恢復控制。
- 直向、橫向與旋轉後，關閉按鈕可見，經文保持直排，揭示進度不重置。
- 經紙與筆在原始場景比例下清楚可辨，且風格、光源和透視與中央長桌一致。
- 全程無音效、無分數、無倒數、無宣傳式收尾。

## 12. 完成條件

只有同時符合以下條件才視為完成：

1. 中央長桌左端出現符合原場景風格的經紙與筆。
2. 玩家能從可行走區靠近，看到名稱「抄寫心經」，且不誤觸相鄰互動。
3. 第一次使用手機的訪客能從短文字與一次指尖示範理解操作。
4. 手指、滑鼠與鍵盤皆可揭示經文；正常手勢約 10–15 秒完成。
5. 經文只從七段已校對的玄奘譯本短句中抽選，同一分頁生命週期內保持不變。
6. 互動可隨時關閉，重新開啟時霧層重置但句子不變。
7. 體驗完全安靜，沒有遊戲化回饋、資料上傳或宣傳式收尾。
8. 畫布失敗、減少動態偏好、裝置旋轉與鍵盤操作都有可用的替代行為。
9. 自動測試與桌機、手機瀏覽器驗收全部通過。
