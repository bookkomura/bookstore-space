# 小村碎碎念信封卡片設計

## 目標

讓「小村碎碎念」的期數選擇卡明確呈現為信封，並讓使用者不用閱讀文字也能辨識目前開啟的期數。

## 視覺與互動

- 每張期數卡維持米色方形信封與既有日期、標題文字。
- 卡片右上角放置小型郵票示意；以色塊與虛線框呈現，不使用外部圖片或文字內容。
- 未選取的卡片不顯示封口折線或三角形。
- 選取的卡片在方形信封上方顯示同色系三角形封蓋，表示信封已打開；既有陰影與微幅上移的選取回饋保留。
- 郵票與封蓋只作視覺裝飾，對輔助技術隱藏；按鈕既有名稱、選取狀態與鍵盤操作不變。

## 實作範圍

只調整 `NewsletterArchive.vue` 的期數卡標記與 scoped CSS，以及它的元件測試。不得改變電子報資料、選期行為、捲動重設、外部連結安全屬性或行動版橫向捲動。

## 驗收

- 每張期數卡都有一個隱藏於輔助技術的郵票裝飾。
- 只有選取中的期數卡具有隱藏於輔助技術的三角形封蓋。
- 未選取卡不含斜線封口視覺。
- 現有 `NewsletterArchive` 行為測試全部持續通過。
