# 拾字成詩載入動畫設計

## 目標

使用者從書局空間開啟「拾字成詩」時，外部上傳頁面尚未完成載入的空白等待時間，應以符合 2D 遊戲與詩集意象的轉場取代。使用者已選定「墨跡成詩」方向，並保留載入文字「正在鋪開詩頁⋯⋯」。

## 範圍

只調整 `PoemUploadOverlay` 的 iframe 載入前視覺狀態；不變更外部網址、iframe 的無 `sandbox` 設定、關閉行為、遊戲輸入凍結機制或上傳功能。

## 體驗流程

1. 使用者開啟「拾字成詩」後，覆蓋層立即出現深色書頁底。
2. 以一個柔和墨暈為中心，「拾、字、成、詩」依序從模糊中顯影；四字落定後，底部留下細墨線。
3. 載入文案顯示為「正在鋪開詩頁⋯⋯」。首輪顯影約 1.2 秒。
4. 若 iframe 尚未完成，墨暈以低幅度、低頻率呼吸，持續表達工作中但不妨礙閱讀。
5. iframe 觸發 `load` 後，載入層與文字迅速淡出，露出已載好的上傳頁面。
6. 使用者啟用系統的「減少動態效果」時，停用所有位移、縮放與循環，只顯示靜態墨暈、四字與載入文案；完成載入時仍可直接切換。

## 視覺原則

- 使用暖米白字色、深褐黑書頁底與低飽和墨色，延續書局空間的氛圍。
- 動畫只使用 opacity、transform 與簡單的陰影／模糊變化；不引入影像素材、Canvas 或額外套件。
- 載入層位於 iframe 上方，但關閉鍵永遠位於載入層上方，讓等待期間仍能離開。
- 動畫不使用一般轉圈 spinner；語意來自「拾字」與「成詩」。

## 元件與資料流

`PoemUploadOverlay` 新增本地 `isFrameLoading` 狀態，初始為 `true`。iframe 的 `load` 事件將它設為 `false`；載入層以此狀態顯示／淡出。iframe 會維持即刻建立與既有 URL，不延後或重建請求。

載入層以純 Vue 模板與 scoped CSS 實作，內含：墨暈裝飾、四個文字元素、載入文案。CSS 的 `prefers-reduced-motion: reduce` 覆寫所有動畫。

## 失敗與邊界

- 第三方 iframe 未載入或網路極慢時，載入提示持續存在；不將尚未確認的 `error` 事件視為成功。
- iframe 的跨網域內容不可由父頁讀取，因此只依賴其可用的 `load` 事件，不檢查內部 DOM。
- 關閉按鈕保持原有 `close` 事件與可存取名稱，使用者可隨時取消等待。

## 驗證

- 元件測試驗證：iframe URL、title、無 `sandbox`、全螢幕覆蓋層及關閉事件仍成立。
- 新增載入狀態測試：初始可見「正在鋪開詩頁⋯⋯」，iframe 觸發 `load` 後載入層離開 DOM 或不可見。
- 靜態樣式測試或手動確認：載入層高於 iframe、關閉鍵高於載入層；`prefers-reduced-motion` 停止動畫。
- 手動驗收：在網路較慢的環境開啟「拾字成詩」，確認不再出現無意義空白、可關閉、載入完成後可正常上傳。
