隱私權政策

最後更新日期：2026 年 8 月 26 日

本政策說明小村閱讀的 Bookstore Space Newsletter Sync 如何透過 Google Gmail API 存取、使用、保存及分享 Google 使用者資料。

服務目的

本服務用於把指定寄件者寄至管理信箱、主旨含有「小村碎碎念」的電子報， 自動整理並發布至小村閱讀網站的公開電子報檔案室。

存取的 Google 使用者資料

本服務使用 Gmail 唯讀權限 gmail.readonly，監聽收件匣更新， 並讀取郵件的寄件者、主旨、標籤、寄送時間、內文、連結及內嵌圖片。 只有符合指定寄件者、指定主旨及收件匣條件的郵件會進一步處理。

本服務不會寄送、刪除、移動或修改 Gmail 郵件。

資料用途

符合條件的電子報資料只用於辨識重複郵件、解析電子報內容、發布公開檔案， 以及觸發網站內容重新部署。本服務不使用 Google 使用者資料進行廣告、行銷分析、 信用評估或建立使用者輪廓。

資料保存與刪除

  • Google OAuth 憑證以受限制的雲端密鑰服務保存。
  • 郵件識別碼、處理狀態與錯誤紀錄保存在 Google Cloud，供同步、除錯及防止重複發布使用。
  • 電子報的主旨、寄送日期、內文、連結及圖片保存在 Storyblok，並透過小村閱讀網站公開呈現。

資料只在提供及維護電子報檔案功能所需期間保存。如需停止 Gmail 存取、 撤銷授權或要求刪除相關資料，請使用下方聯絡方式提出申請。

資料分享

資料只會提供給執行本服務所需的處理平台，包括 Google Cloud、Storyblok 與 Cloudflare Pages。本服務不出售 Google 使用者資料，也不會把資料提供給第三方用於廣告。 除提供本功能、維護安全或依法配合外，不會將資料移轉給其他第三方。

Google API Limited Use

本服務使用從 Google Workspace API 取得的資訊時，會遵守 Google API Services User Data Policy， 包括其中的 Limited Use requirements。

資料安全

我們使用存取權限控管、受管理的雲端密鑰與加密連線保護資料，並將 Gmail 權限限制為服務運作所需的唯讀範圍。

政策更新

若資料處理方式改變，本頁會同步更新內容及最後更新日期。

聯絡方式

如對本政策、Gmail 資料使用、授權撤銷或資料刪除有任何疑問，請聯絡 bookkomura@gmail.com。
